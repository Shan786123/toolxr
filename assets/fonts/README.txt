# assets/fonts/

This folder holds local font files for offline use.

Run install-libs.sh or install-libs.bat to auto-download:
  SpaceMono-Regular.woff2   — Logo and code block font
  SpaceMono-Bold.woff2      — Logo bold weight
  DMSans.woff2              — Main body font

If empty, toolxr.html loads fonts from Google Fonts CDN.
Fonts are cosmetic only — the site works without them.
