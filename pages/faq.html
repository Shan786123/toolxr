Frequently Asked Questions

Answers to the most common questions about ToolXr.

Last updated: May 4, 2026

General

Is ToolXr really free?

Yes, completely. All 38 tools are free with no hidden paywalls, no file size limits, and no premium tier. We don't run ads either.

Do I need to create an account?

No. ToolXr has zero sign-up. Open the site, click a tool, use it. Done.

How does ToolXr make money?

Currently ToolXr is a free open-source project. We may introduce optional donations or a hosted pro version in the future, but all current tools will always remain free.

Privacy & Security

Do you upload my files to your servers?

For 33 out of 38 tools — no. These tools run entirely in your browser and your files never leave your device. Only the 5 backend converter tools (Word/Excel/PPT) send files to the server, where they are deleted within 30 minutes.

Can you see my PDFs or images?

No. For browser-based tools, we literally cannot see your files — they're processed on your device. For server-side tools, files are processed by automated code and deleted automatically.

Is the connection secure?

Yes. When using a hosted version, all connections use HTTPS encryption. When running locally, files never leave your network.

Tools

Why aren't Word/Excel/PPT tools working?

These 5 tools require the backend server (Node.js + LibreOffice). Run bash start.sh (Mac/Linux) or double-click start.bat (Windows) to start the backend.

The OCR tool isn't extracting text correctly

Tesseract.js works best on clear, high-resolution scans. Low quality or handwritten text may have lower accuracy. For best results use images at 300 DPI or higher.

The Remove Background tool gives an error

This tool requires a free API key from remove.bg. Sign up for free (50 uses/month) and paste your API key into the tool's input field.

Can I use ToolXr offline?

Yes! Run bash install-libs.sh from your ToolXr folder. It downloads all JavaScript libraries locally and patches index.html to use them. After that, 37 tools work with zero internet connection.

Technical

Which browsers are supported?

Chrome, Firefox, Edge, and Safari (latest versions). The site works best in Chrome or Edge for maximum performance.

Can I host ToolXr on my own server?

Yes! ToolXr is designed to be self-hosted. See the README.md included in the package or the Developer panel inside the app for full instructions.

The site loads slowly the first time

The first load downloads JavaScript libraries from CDN (pdf-lib, Tesseract.js, etc.). After that, your browser caches them and subsequent loads are instant. Run install-libs.sh to host libraries locally for faster initial loads.
